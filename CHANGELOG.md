# Changelog

## 0.1.0, 2026-09-13

First release.

- Five-Dimension AI Readiness Assessment v1.1 as YAML, with scoring template.
- TRACE Framework v1.1 as YAML, with task inventory template.
- Four-Question AI Governance Baseline v1.1 as YAML, with AI deployment register template.
- Governed Agentic RAG reference architecture v1.0: 16 controls mapped to ISO/IEC 42001:2023 and MAS FEAT, task state machine, example policy rules, risk register, operating metrics, basis trace.
- JSON Schema for the task envelope with a validated example.
- Validator (`npm test`).

Not yet included: Return on Employee, Measurement-Before-Prediction and the Governed Cognitive Layer (Layer 8). These are on the roadmap once their reference pages have a form that reduces to fields.
